\begin{abstract}
This report details the implementation of a fully-featured Active Inference agent within the COBWEB simulation environment. The agent operates as a Partially Observable Markov Decision Process (POMDP) utilizing Variational Free Energy minimization for both perception (inference) and action (planning), and incorporates Active Learning to learn environmental dynamics over time.
\end{abstract}
\section{System Updates and Architecture}
\subsection{Core Components}
The implementation introduces a new AI architecture to the `org.cobweb.cobweb2.impl.ai` package:
\begin{itemize}
    \item \textbf{ActiveInferenceController.java}: The primary agent logic. It maintains internal matrices representing the Generative Model ($A, B, C, D$) and executes the perception-action loop.
    \item \textbf{Matrices.java}: A newly developed utility class providing essential Tensor operations (Dot product, Matrix-Vector multiplication) and Probability functions (Softmax, Entropy, KL Divergence, Dirichlet expectations) required for the math.
    \item \textbf{ActiveInferenceAgentParams.java}: Configuration class defining prior preferences (e.g., strength of preference for Food vs. Energy conservation).
    \item \textbf{UI Integration}: A dedicated `ActiveInferencePanel` allows users to configure these agents directly from the simulation GUI.
\end{itemize}
\subsection{Refactoring from V1 (Reactive)}
The initial reactive prototype (which mapped observations directly to values) has been largely replaced. The new V2 implementation maintains an explicit **Belief State** ($Q(s)$) and learns the consequences of actions, shifting from a heuristic agent to a learning model-based agent.
\section{Mathematical Formulation}
The agent minimizes Variational Free Energy ($F$) to approximate the posterior probability of hidden states, and minimizes Expected Free Energy ($G$) to select policies.
\subsection{Generative Model}
The joint probability density of observations $o$, states $s$, and policies $\pi$ is defined as:
\begin{equation}
P(o, s, \pi) = P(\pi) P(s_0) \prod_{t=1}^{T} P(o_t|s_t) P(s_t|s_{t-1}, \pi_{t-1})
\end{equation}
Implemented Matrices:
\begin{itemize}
    \item $\mathbf{A}$ (Likelihood): $P(o|s)$, mapping hidden states (Safe, Food, Obstacle) to visual observations.
    \item $\mathbf{B}$ (Transition): $P(s_{t+1}|s_t, u)$. This is maintained as a set of Dirichlet distributions $Dir(\mathbf{b})$, allowing the agent to learn transition probabilities from counts.
    \item $\mathbf{C}$ (Preferences): $P(o)$, a fixed prior over observations (Agent prefers seeing Food).
    \item $\mathbf{D}$ (Prior): $P(s_0)$, initial state beliefs.
\end{itemize}
\subsection{Perception (Minimizing $F$)}
At each time step, the agent infers the hidden state $s_t$ by variational message passing (approximated as a fixed-point update):
\begin{equation}
Q(s_t) = \sigma \left( \underbrace{\ln \mathbf{A} \cdot o_t}_{\text{Evidence}} + \underbrace{\ln (\mathbf{B}_{u_{t-1}} \cdot Q(s_{t-1}))}_{\text{Prior}} \right)
\end{equation}
where $\sigma$ is the softmax function.
\subsection{Active Learning}
The agent learns the transition dynamics ($\mathbf{B}$) by updating Dirichlet concentration parameters $\alpha$ based on the inferred transition:
\begin{equation}
\alpha_{next, prev, action} \leftarrow \alpha_{next, prev, action} + \eta \cdot Q(s_{next}) \cdot Q(s_{prev})
\end{equation}
This allows the agent to discover environmental rules (e.g., "Moving forward into an obstacle results in staying at the obstacle state").
\subsection{Action (Minimizing $G$)}
Policies $\pi$ (actions) are selected to minimize Expected Free Energy $G(\pi)$:
\begin{equation}
G(\pi) = \sum_{\tau} G(\pi, \tau)
\end{equation}
\begin{equation}
G(\pi, \tau) \approx \underbrace{- \mathbf{E}_{Q(o|\pi)}[\ln P(o)]}_{\text{Extrinsic Value}} - \underbrace{H[Q(o|\pi)]}_{\text{Epistemic Value}}
\end{equation}
The code calculates:
\begin{enumerate}
    \item **Extrinsic**: Match between predicted observations and Preferences ($\mathbf{C}$).
    \item **Epistemic**: Entropy of predicted observations (seeking novel states/information).
\end{enumerate}
\section{Justification as Active Inference}
This implementation constitutes a faithful Active Inference agent because:
\begin{enumerate}
    \item **First Principles**: It does not maximize "Reward" explicitly. Instead, it minimizes divergent Probability Distributions (Free Energy). "Reward" is encoded simply as a Prior Belief ($\mathbf{C}$) that the agent works to fulfill.
    \item **Epistemic Drive**: The inclusion of the Entropy term in $G$ means the agent is naturally curious. It will explore actions where the outcome is uncertain, distinct from standard Reinforcement Learning which requires explicit exploration noise or bonuses.
    \item **Biological Plausibility**: The separation of Perception (State Estimation) and Action corresponds to cortical hierarchies found in biological brains.
\end{enumerate}
\section{Future Improvements}
\begin{itemize}
    \item **Temporal Depth**: Currently, the agent looks ahead only 1 step ($G$ roughly calculated for immediate future). Deep Active Inference ($t > 1$) would allow for complex path planning.
    \item **Hierarchical Models**: Implementing a second layer of states (e.g., "Context" or "Room Type") that evolves slower than the low-level states would allow for more abstract reasoning.
    \item **Precision Learning ($\gamma$)**: Currently, the precision of beliefs is fixed. Learning the expected precision (confidence) of observations would allow the agent to ignore noise dynamically.
    \item **Parameter Learning for A**: While B-matrix learning is implemented, learning the A-matrix would allow the agent to learn *what* objects look like, not just how they move.
\end{itemize}
